Key Decisions

• Pivoted Ursula from a from-scratch Tauri terminal to a Code-OSS (VS Code) fork
↳ VS Code extensions (Kilo Code) need the Extension Host + full Electron workbench — impossible on Tauri/Rust without reimplementing the host.
• Marketplace = Open VSX, not Microsoft Marketplace
↳ Microsoft Marketplace ToS forbids non-Microsoft clients; Open VSX is the legal equivalent, carries Kilo Code/Cline/Continue.
• Project lives at ~/MyApps/ursula-ide (spaceless), NOT ~/My Apps/
↳ Spaces in the path break node-gyp's make (unquoted paths -> sqlite3/node-pty fail to compile).
• Build with Node 24.15.0 exactly
↳ VS Code's preinstall.ts enforces the .nvmrc pin; Node 24.11.1 is rejected (minor 11 < 15).
• Gutted COLOR_THEME_DARK_INITIAL_COLORS when setting Bone+Gold as default
↳ It was a map of VS Code blue #0078D4 overrides that would overwrite the gold on first boot.
• Kept the Tauri project (~/My Apps/ursula-terminal) preserved, not deleted
↳ Portable-asset source: Bone+Gold tokens, xterm decoration-clipping fix, workspace configs, OSC 133 shell-integration.
